## Ближайшие задачи

1. **Сервер документов**  
   Загрузка файлов не только в IndexedDB браузера, а на сервер (Vercel Blob / аналог), чтобы менеджер видел пакет в админке.

2. **Админка менеджера**  
   Разделы: клиенты / заказы / чат / документы клиента / смена стадий отслеживания.  
   Вход: `/admin` (отдельный от клиентского `/cabinet`).

3. **Письма восстановления пароля**  
   Подключить Resend: `RESEND_API_KEY`, `EMAIL_FROM`, `APP_URL` в Vercel  
   (сейчас без ключа показывается dev-ссылка).

4. **ООО и реквизиты VED**  
   Когда откроете компанию — реквизиты на сайт (О компании / подвал) + шаблоны договоров с вашими данными.  
   Клиентские реквизиты уже заложены слотом в «Документах».

5. **Ступенчатая маржа услуг VED**  
   TODO в `src/lib/pricing/margins.ts` — разные % на дорогие авто.

6. **Живой каталог (Carapis / Autohome)**  
   Вместо демо-данных.

7. **Отслеживание ↔ документы**  
   Прогресс пакета уже на этапе «Документы»; дальше — авто/ручной перевод стадий менеджером.
